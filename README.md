# 🧁 Bakery Management System

A full-stack web application built to manage bakery operations, order processing, and inventory tracking.

## 🛠️ Tech Stack
- **Frontend:** React.js
- **Backend:** Python / Django (REST API)
- **Database:** PostgreSQL
- **Media Hosting:** Cloudinary

## ✨ Key Features
- **Product Management:** Add, update, and manage bakery items dynamically.
- **Image Uploads:** Product and user image storage powered by Cloudinary.
- **Security:** Configured with CORS and CSRF middleware for secure client-server data transfer.
